# v3.0.4

## Fixed

- **Nodes the minimap showed reached the radar only at the next check.** When a check
  had to wait for a free cursor — a window open, chat scrolled — the nodes it then found
  were dropped again within a second and turned up only one check later.
- **Nodes vanished from the radar after combat.** A node not confirmed for a minute was
  dropped even while NodeRadar could not look, for example during a long fight. Nodes
  in range now leave the radar only when a check no longer finds them.
- **Nodes at the edge of the range blinked off now and then.** A node close to the
  edge of the minimap was not confirmed by the checks and dropped every minute.
- **A node that is not there stayed on the radar.** When a vein next to another node of
  the same kind was mined out while NodeRadar looked for it, the search could end beside
  the remaining node and show a second one there — and the checks kept confirming it.
  A search now counts only a spot that holds more nodes than the radar already shows
  there, and a single spot is read narrow enough to tell two nodes 15 yards apart.
- **Addon buttons and map pins at the minimap moved off their place.** An addon that
  showed or refreshed its minimap button or pin while NodeRadar was reading the minimap
  placed it for the shrunk map — Guidelime does so whenever its window opens or closes,
  Details right after login. Anything moved during a reading now gets its place back,
  and NodeRadar leaves the minimap alone for five seconds after a loading screen, while
  addons set up their buttons.
- **GatherMate2 data switched off for the whole continent.** Where GatherMate2's spawn
  points do not match the world, NodeRadar stops trusting them — but it did so for the
  whole continent after three odd finds, one of them a vein counted twice while being
  mined. It now does so only for the zone they were found in, and counts each spot once.

## Changed

- **Much shorter blink.** A reading now takes a single frame: a regular check keeps
  the minimap away for about half as long as before, a search for a new node about a
  third.
- **A spawn point coming into range reads only its part of the range.** Riding past
  spawn points blinks shorter.
- **No extra check after every skill-up.** A skill point now triggers a check only
  when it changes which nodes your filters show.
