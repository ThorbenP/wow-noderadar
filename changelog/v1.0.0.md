# v1.0.0

First public release.

## Features

- **Radar** centred on the screen, turning with your view, showing every herb or
  ore node whose presence the scan has confirmed. Range rings, axes and a heading
  marker; distance in yards on each icon.
- **Targeted scanning**: the imported GatherMate2 database supplies the candidate
  positions, so a pass costs a handful of samples instead of a blind sweep of the
  whole tracking range. An
  unconfirmed candidate is probed at four extra points around its aimed position
  in case another blip covers it.
- **Blind sweep fallback** when the database is empty or knows nothing about the
  current zone: the tracking range is covered in slices, so the addon works
  without importing GatherMate2_Data at all, only slower.
- **Addon pins are excluded**: minimap pins from GatherMate2 or Questie sit exactly
  where a node is only *expected*, so their mouse interaction is switched off
  during a pass. Only blips the client itself draws count as proof.
- **Invisible while scanning**: map image, tracking blips, player arrow, tooltip
  and minimap clicks are all suppressed for the duration of a pass and restored
  afterwards.
- **Hit expiry pauses** whenever scanning is impossible — a held mouse button means
  "cannot look", not "the node is gone".
- **Options panel** with radar radius, icon size, scan interval, grid, distance
  labels, autostart, a draggable control window and a restore-defaults button.
- `/nr`, `/nr options`, `/nr debug`.
