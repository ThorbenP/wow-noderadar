# v3.0.3

## Fixed

- **A Lua error with the cursor on some frames.** A protected frame under the cursor
  made NodeRadar stop with "attempt to compare … a secret string value".
- **No sound for a vein you are still mining.** A vein that takes several swings was
  taken off the radar after the first and announced as new when it was seen again.

## Changed

- **No checks where nothing you want can stand.** With GatherMate2, the minimap is
  checked only while a spawn point of a node you want is in range or such a node is on
  the radar — no more check once a minute anywhere else.
- **No blink right after you let go of the mouse.** After turning the camera, holding a
  mouse button, or having the cursor on a window or a unit, NodeRadar waits two
  seconds before it reads again.
